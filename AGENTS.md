# Agent instructions entrypoint

This repository uses task-scoped documentation.

Read only the documents relevant to the current task:
- Always: `docs/rules/general-rules.md`
- Implementation work: `docs/rules/implementation-rules.md`
- Architecture changes: `docs/architecture/purpose.md` first, `docs/architecture/roadmap.md` second, then `docs/rules/adr-rules.md`, `docs/adr/README.md`, `docs/adr/process.md`
- Scenarios the engine is measured against: `docs/architecture/scenarios/README.md`
- Architecture ideas not yet decided: `docs/architecture/notes/README.md`
- Documentation work: `docs/rules/documentation-rules.md`
- Git and branches: `docs/processes/git-workflow.md`
- Current architecture: `docs/architecture/overview.md`
- Session notes: `docs/sessions/README.md`
  - For every new session, follow the lifecycle protocol in this document from start to closure/interruption.

Do not read unrelated documentation just because it exists.

Documents may be created only inside the document map defined in `docs/rules/documentation-rules.md`.
