# Architecture note template

Copy this structure for every note. The header fields are mandatory; the body is free.
See `README.md` for what a note is, its lifecycle and how it is consumed.

# <title>

- **Date:** YYYY-MM-DD (the day the note was opened)
- **Trigger:** where the idea came from (which session, discussion or observation)
- **Status:** `open` | `promoted → <where>` | `dropped (<reason>)`
- **Affected:** ADRs and architecture areas this touches, or `—`

<free body — prose, lists, schemas, competing options, open questions, any form>
