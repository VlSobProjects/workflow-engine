# Scenario template

Copy this structure for every class 2 scenario and for the walkthrough header of every class 4
example. The header fields are mandatory; the body is free.

# <title>

- **Identifier:** `<short-name>`
- **Class:** `2` | `4`
- **Answerers:** who answers each step — a human, an external program, a model — by step
- **Input data:** the prepared data the run starts from, and where it lives
- **Expected paths:** the paths through the data the run is expected to take, and what selects each
- **Ends with:** how the run ends on each path — end of workflow, failure code, handover
- **ADRs exercised:** the live list of ADRs this scenario exercises, or `—`

<free body — steps, data shapes, open decisions the scenario lacks, any form>
