# Rules index

Use this index to choose the relevant rule set for the task.

## Rule categories
- `general-rules.md` — common rules for all work
- `adr-rules.md` — rules for architecture decisions
- `implementation-rules.md` — rules for code changes
- `documentation-rules.md` — rules for documentation changes

## Selection rule
- Every task: read `general-rules.md`
- Architecture decisions: read `adr-rules.md`, `../adr/README.md` and `../adr/process.md`
- Architecture ideas not yet decided: read `../architecture/notes/README.md`
- Code changes: read `implementation-rules.md`
- Documentation changes: read `documentation-rules.md`
- Git and branches: read `../processes/git-workflow.md`
- Sessions: read `../sessions/README.md`

`AGENTS.md` at the repository root is the entrypoint that routes to this index.
